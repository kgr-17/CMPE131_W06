# Daily Log — September 17, 2026

## Today's Goal

Make start times optional, add estimated time, and give tasks a Priority section and a Calendar section. Keep the future recommendation system on the to-do list while our teammate designs it.

## What We Did

### 1. Made start time optional

- A task can now have an end date and time without a start time.
- The form has an optional **Include a start time** checkbox, turned off by default.
- If both times are entered, the end still has to be after the start.
- Updated the database rule and kept existing tasks and schedules.

### 2. Added estimated time

- Added an optional estimate in minutes or hours.
- For example, 1.5 hours is saved as 90 minutes and shown as 1 hr 30 min.
- The estimate stays separate from the task's start and end times.
- Added checks for invalid values. Estimates can range from 1 minute to 7 days.

### 3. Added Priority

- Shows pending tasks that have an end time.
- Sorts by the earliest end time first. Overdue tasks stay at the top and are marked.
- Tasks with the same deadline use their ID to keep the order stable.
- Estimated time does not change priority yet.
- All tasks, including those without dates, are still available in the All tasks section.

### 4. Added Calendar

- Added a month view with previous/next month and Today buttons.
- Select a day to see its tasks. Arrow keys can also move between days.
- Tasks with only an end time appear on their deadline date.
- Tasks with a start and end appear on the days their schedule covers.
- Dates use English, and times use the viewer's local time zone.
- Added a layout for smaller screens, using task counts inside calendar days.
