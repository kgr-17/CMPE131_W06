# Daily Log — September 9, 2026

## Today's Goal

Build the first useful part of our task organizer: add a task, save it, and use it from a simple webpage.

## What We Did

### 1. Planned the first backend feature

- Read the project rules and checked the existing code.
- Used the React, Express, PostgreSQL, and Docker setup already in the project.
- Kept the first step focused on adding tasks.

### 2. Built task saving

- Added a backend endpoint to create a task.
- Made the task name required and notes optional.
- Gave each saved task an ID, a pending status, and a creation date.
- Connected the backend to PostgreSQL so tasks stay saved.
- Added checks for missing names, long text, and invalid requests.
- Added clear error messages without showing private server details.

- Replaced the starter page with a clean, Apple-inspired layout.

- Made the layout adjust to desktop and phone screens.
- Added loading, empty-list, success, and error messages.
- Kept typed text in the form when a save fails.

### 4. Made the app use English

- Set task dates and number formatting to English.
- Replaced browser-generated form popups with English messages from the app.

- Showed the saved schedule and location in the task list.
- Updated the existing database without removing earlier tasks.

### 6. Wrote project guides

- Updated the README and Docker guide.
